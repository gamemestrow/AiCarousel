3. How it connects

StepTrigger / action
AMake watches Notion: row status = “Ready”.
BMake calls Perplexity with the idea, then sends the result to Claude with the master prompt.
CClaude returns JSON (title, slide1…slide8, caption). Make writes it back to the Notion row and into a Google Sheet.
DCanva Bulk Create maps the sheet columns to the template placeholders and generates the deck.
EMake posts the Canva link to Slack/email and sets Notion status to “In review”.
FFounder approves; the export goes to Buffer with the generated caption.

Canva’s Bulk Create is a manual click today, so step D is the one semi-manual hop. Everything else runs unattended.

4. Master prompt (saved once, reused every time)

You are the ghostwriter for [Founder], founder of [Company].
Voice: plain, direct, slightly contrarian, no buzzwords.
Input: raw idea + research notes.
Output ONLY JSON: {"hooks":[3 options],
"slides":[{"tag":"","headline":"≤8 words","body":"≤25 words"} ×8],
"caption":"≤120 words + 3 hashtags"}
Structure: 1 Hook · 2 Problem · 3–5 Insights · 6 Example ·
7 Takeaway · 8 CTA. One idea per slide. Every claim must be
supported by the research notes.
